# Code of conduct

## The standard

Be straightforward and be kind. Disagree about the work, not about the person.

Specifically:

- **Argue from evidence.** This project's whole premise is that claims should be
  checkable. Bring the benchmark run, the failing test, the citation.
- **Accept correction.** Being wrong in public is the normal cost of working in
  public. Say "you're right", fix it, move on.
- **Say what you did not verify.** "I did not test this on Windows" is a
  contribution. Silence about it is not.
- **Assume competence.** People asking basic questions are usually new, not
  careless.

Not acceptable: harassment, personal attacks, demeaning comments, sustained
disruption, publishing others' private information, or unwelcome attention of
any kind.

## Scope

This applies in the repository, its issues and pull requests, and anywhere
someone is representing the project.

## Enforcement

Report to the maintainers through a private GitHub security advisory or by
emailing the address in `GOVERNANCE.md`. Reports are handled confidentially.

Maintainers may warn, edit or remove contributions, or ban a participant.
Enforcement decisions are recorded, and the reasoning is given to the person
affected.

Maintainers are held to this standard at least as strictly as anyone else.

## Attribution

This is an independently written code of conduct. It is not derived from the
Contributor Covenant or any other document; it was written for this project and
can be changed by ordinary pull request.
